# Airren

Luxury stays with a guest-first loop. Search, open a home, and place a demo hold. No payments.

## Local

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

```bash
npm test
npm run lint
npm run build
```
